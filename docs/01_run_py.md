# Документация: run.py

## Назначение

Файл `run.py` является **точкой входа** в Flask-приложение Demo27. Это единственный файл в корне проекта, который запускает веб-сервер. При его выполнении инициализируется всё приложение: создаётся экземпляр Flask через фабричную функцию `create_app()`, настраиваются все компоненты, инициализируется база данных, и запускается сервер разработки.

## Структура

Файл состоит из трёх логических частей:

### 1. Импорт фабрики приложения
```python
from app import create_app
```
Импортирует функцию `create_app()` из пакета `app/`. Это фабричная функция, которая создаёт и настраивает всё Flask-приложение (инициализация расширений, регистрация blueprints, настройка конфигурации и т.д.).

### 2. Создание приложения
```python
app = create_app()
```
Создаёт экземпляр Flask-приложения. На этом этапе:
- Загружается конфигурация из `.env` файла
- Инициализируются расширения (SQLAlchemy, Flask-Migrate, Flask-Login)
- Регистрируются все Blueprint (маршруты)
- Настраиваются обработчики ошибок
- Создаются таблицы базы данных

### 3. Запуск сервера
```python
if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)
```
При запуске файла напрямую (`python run.py`) запускается встроенный сервер Flask:
- **host='0.0.0.0'** — сервер доступен по всем сетевым интерфейсам (включая локальную сеть)
- **port=5000** — стандартный порт для Flask
- **debug=True** — режим отладки с автоперезагрузкой и детальными сообщениями об ошибках

## Ключевая логика

- Файл использует **паттерн фабрики** (Factory Pattern) для создания приложения — это позволяет легко тестировать и настраивать приложение для разных сред (development, production, testing)
- Минимальный размер файла обусловлен тем, что вся сложная логика инкапсулирована в `app/__init__.py`
- Режим `debug=True` подходит только для разработки; в продакшене следует использовать `debug=False`

## Зависимости и связи

| Элемент | Тип связи | Описание |
|---------|-----------|----------|
| `app/__init__.py` | Импорт | Вызывает `create_app()` — фабрику приложения |
| `.env` | Конфигурация | Загружается внутри `create_app()` для переменных окружения |
| `web/` | Статические файлы | Служит папкой templates и static для Flask |
| PostgreSQL | База данных | Подключение настраивается через `create_app()` |

## Примеры использования

### Запуск сервера разработки
```bash
python run.py
```
После запуска приложение будет доступно по адресу: `http://localhost:5000`

### Запуск с переопределением окружения
```bash
set FLASK_ENV=production && python run.py
```

## Важные замечания

1. **Безопасность**: `debug=True` в продакшене — угроза безопасности. Используйте gunicorn или другой WSGI-сервер для production.
2. **Порт 5000**: Может быть изменён путём передачи параметра `port` в `app.run()`.
3. **Один файл**: `run.py` намеренно минималистичен — вся конфигурация вынесена в `app/__init__.py` и `app/config.py`.
