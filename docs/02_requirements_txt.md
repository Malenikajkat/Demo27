# Документация: requirements.txt

## Назначение

Файл `requirements.txt` содержит список всех **Python-зависимостей** проекта Demo27 с минимальными версиями. Используется менеджером пакетов `pip` для установки необходимых библиотек в виртуальное окружение. Файл обеспечивает воспроизводимость среды разработки и деплоя.

## Список зависимостей

| Пакет | Версия | Назначение |
|-------|--------|------------|
| **Flask** | >=3.0.0 | Основной веб-фреймворк. Обеспечивает маршрутизацию, рендеринг шаблонов, обработку запросов. |
| **Flask-SQLAlchemy** | >=3.1.0 | ORM-расширение для Flask. Позволяет работать с базой данных через Python-объекты (SQLAlchemy). |
| **Flask-Login** | >=0.6.0 | Управление сессиями и аутентификацией пользователей. Обрабатывает вход/выход, хранение данных пользователя в сессии. |
| **Flask-Migrate** | >=4.0.0 | Миграции базы данных на основе Alembic. Позволяет изменять схему БД без потери данных. |
| **Werkzeug** | >=3.0.0 | Ядро Flask. Включает хеширование паролей (`generate_password_hash`, `check_password_hash`), WSGI-утилиты. |
| **Pillow** | >=10.0.0 | Библиотека для работы с изображениями. Используется для генерации пазл-капчи (разрезание изображений, конвертация в base64). |
| **psycopg2-binary** | >=2.9.0 | Адаптер PostgreSQL для Python. Позволяет подключаться к PostgreSQL из Python. `-binary` версия включает предкомпилированный драйвер. |
| **python-dotenv** | >=1.0.0 | Загрузка переменных окружения из `.env` файла. Позволяет хранить конфигурацию вне кода. |
| **alembic** | >=1.13.0 | Движок миграций для SQLAlchemy. Используется Flask-Migrate для управления изменениями схемы БД. |

## Ключевые особенности

### Версионирование
Все зависимости указаны с оператором `>=`, что означает «версия не ниже указанной». Это обеспечивает:
- Совместимость с минимальными стабильными версиями
- Возможность обновления до более новых версий
- Отсутствие жёсткой фиксации (нет `==`)

### Группы зависимостей

#### Веб-фреймворк
- `Flask`, `Werkzeug` — основа всего приложения

#### Работа с базой данных
- `Flask-SQLAlchemy`, `psycopg2-binary`, `alembic`, `Flask-Migrate`

#### Аутентификация и безопасность
- `Flask-Login`, `Werkzeug` (хеширование паролей)

#### Работа с файлами и конфигурацией
- `python-dotenv` (.env файлы)
- `Pillow` (обработка изображений капчи)

## Установка

### Создание виртуального окружения
```bash
python -m venv venv
venv\Scripts\activate  # Windows
```

### Установка всех зависимостей
```bash
pip install -r requirements.txt
```

### Экспорт актуальных зависимостей
```bash
pip freeze > requirements.txt
```

## Зависимости между пакетами

```
Flask
├── Werkzeug (хеширование, WSGI)
├── Flask-SQLAlchemy
│   └── SQLAlchemy (ORM)
├── Flask-Login (сессии)
├── Flask-Migrate
│   └── Alembic (миграции)
├── python-dotenv (.env)
└── Pillow (капча)
                    └── psycopg2-binary (PostgreSQL)
```

## Важные замечания

1. **psycopg2-binary**: В продакшене рекомендуется использовать `psycopg2` (без `-binary`) с компиляцией из исходников для лучшей производительности и безопасности.

2. **Отсутствие линтеров**: В файле нет инструментов для проверки кода (flake8, black, mypy). Их можно добавить при необходимости.

3. **Нет разделения на environments**: Все зависимости в одном файле. Для сложных проектов рекомендуется разделять на `requirements.txt`, `requirements-dev.txt`, `requirements-prod.txt`.

4. **Безопасность**: Регулярно проверяйте зависимости на наличие уязвимостей через `pip audit` или `safety check`.
