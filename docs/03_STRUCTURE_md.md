# Документация: STRUCTURE.md

## Назначение

Файл `STRUCTURE.md` — это **основная документация структуры проекта** Demo27. Он описывает архитектуру приложения, назначение каждого модуля, каталога и файла. Предназначен для новых разработчиков и тех, кто нуждается в быстром обзоре организации кодовой базы.

## Структура документа

Документ разделён на следующие основные секции:

### 1. Общая архитектура
Описывает трёхуровневую архитектуру приложения:
```
Frontend (HTML/JS) → Flask Blueprints → Services → Repositories → SQLAlchemy Models → PostgreSQL
```
- **Frontend**: HTML-страницы с CSS и JavaScript в каталоге `web/`
- **Blueprints**: Маршруты API в `app/blueprints/`
- **Services**: Бизнес-логика в `app/services/`
- **Repositories**: Доступ к данным в `app/repositories/`
- **Models**: ORM-модели в `app/models.py`
- **PostgreSQL**: Реляционная база данных

### 2. Каталог `app/` — ядро приложения
Подробное описание каждого файла в корне `app/`:

| Файл | Описание |
|------|----------|
| `__init__.py` | Фабрика приложения `create_app()` |
| `config.py` | Классы конфигурации (Dev, Prod, Test) |
| `extensions.py` | Глобальные экземпляры расширений Flask |
| `models.py` | 13 SQLAlchemy-моделей (таблиц БД) |
| `auth.py` | Хеширование и проверка паролей |
| `utils.py` | Утилиты для форматирования данных |
| `puzzle_captcha.py` | Генератор пазл-капчи |

### 3. Каталог `app/blueprints/` — маршруты
Описание 12 Blueprint-файлов с перечислением маршрутов:

| Blueprint | Префикс | Назначение |
|-----------|---------|------------|
| `web.py` | `/` | Рендеринг HTML-страниц |
| `auth.py` | `/api/auth` | Авторизация, регистрация |
| `clients.py` | `/api/clients` | CRUD клиентов |
| `products.py` | `/api/products` | CRUD продукции |
| `materials.py` | `/api/materials` | CRUD материалов |
| `operations.py` | `/api/operations` | CRUD операций |
| `specifications.py` | `/api/specifications` | Спецификации |
| `sales_orders.py` | `/api/sales-orders` | Заказы покупателей |
| `admin.py` | `/api/admin` | Админ-панель |
| `notes.py` | `/api/notes` | API заметок |
| `puzzle_captcha.py` | `/api/captcha` | API капчи |

### 4. Каталог `app/dtos/` — объекты передачи данных
Описание DTO-классов для сериализации данных:
- `ClientDTO`, `ProductDTO`, `MaterialDTO`, `OperationDTO`
- `SalesOrderDTO` + `SalesOrderItemDTO`
- `SpecificationMaterialDTO`, `SpecificationOperationDTO`
- `NoteDTO` (с трансформацией полей)
- `UserDTO`

### 5. Каталог `app/repositories/` — слой доступа к данным
Базовый `BaseRepository` с общими CRUD-методами и специализированные репозитории для каждой модели.

### 6. Каталог `app/services/` — слой бизнес-логики
`BaseService` + сервисы с бизнес-правилами: авторизация, CRUD с DTO, расчёт стоимости заказа.

### 7. Каталог `app/views/` — Class-Based API Views
Альтернативный подход к маршрутизации через классы (наследники `MethodView`).

### 8. Каталог `database/`
- `schema.sql` — полная SQL-схема PostgreSQL
- `seed_data.py` — тестовые данные
- `import_clients.py` — импорт из JSON
- `order_cost_query.sql` — запросы расчёта стоимости

### 9. Каталог `web/` — фронтенд
13 HTML-страниц + CSS-стили. Описание каждой страницы и её функциональности.

### 10. Каталог `tests/`
Конфигурация pytest и тестовые файлы для авторизации и заметок.

### 11. Сводная таблица
В конце документа приведена таблица с количеством файлов по каждому компоненту:

| Компонент | Файлов | Назначение |
|-----------|--------|------------|
| Blueprints | 12 | Маршруты и API |
| DTOs | 8 | Объекты передачи данных |
| Repositories | 9 | Доступ к БД |
| Services | 10 | Бизнес-логика |
| Views | 9 | Class-Based API |
| Frontend | 11 | UI |
| Тесты | 3 | Unit-тесты |
