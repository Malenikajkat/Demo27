# Документация: app/puzzle_captcha.py

## Назначение

Файл `app/puzzle_captcha.py` реализует **генератор пазл-капчи** для защиты формы авторизации от ботов. Реализует требования задания 4 (TZ.md): пользователь должен собрать изображение из фрагментов, после чего система проверяет правильность сборки.

## Класс `PuzzleCaptcha`

### Инициализация

```python
def __init__(self, image_dir: Optional[str] = None, mode: str = "pieces")
```

**Параметры**:
| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `image_dir` | `str` | `"image/"` | Директория с изображениями |
| `mode` | `str` | `"pieces"` | Режим: `"pieces"` или `"grid"` |

**Атрибуты**:
- `self.challenges` — словарь активных капч `{token: challenge_data}`
- `self.image_dir` — путь к изображениям
- `self.image_files` — список файлов изображений
- `self.mode` — текущий режим

### Режимы работы

#### Режим `pieces` (по умолчанию)
Использует 4 отдельных изображения (1.png — 4.png) как фрагменты пазла:
1. Загружает все PNG из `image/`
2. Масштабирует каждое до 200×200
3. Собирает reference-изображение (2×2 сетка)
4. Перемешивает фрагменты
5. Возвращает перемешанные фрагменты + reference

#### Режим `grid`
Разрезает ОДНО изображение на сетку 3×3:
1. Загружает одно изображение
2. Масштабирует до 300×300
3. Разрезает на 9 фрагментов (100×100 каждый)
4. Перемешивает
5. Возвращает фрагменты (reference = None)

### Ключевые методы

#### `generate(image_filename=None) -> dict`

Генерирует новую капчу.

**Возвращает**:
```python
{
    "token": "abc123...",              # 32-символьный токен
    "fragments": ["data:image/png;base64,...", ...],  # base64 фрагменты
    "grid_size": 2,                     # 2×2 или 3×3
    "correct_order": [0, 1, 2, 3],     # правильный порядок
    "num_pieces": 4,                    # количество фрагментов
    "reference_image": "data:image/png;base64,...",  # образец (только pieces)
    "shuffled_indices": [2, 0, 3, 1],  # текущий порядок
}
```

#### `verify(token: str, fragment_order: list[int]) -> bool`

Проверяет правильность сборки пазла.

**Параметры**:
| Параметр | Тип | Описание |
|----------|-----|----------|
| `token` | `str` | Токен капчи |
| `fragment_order` | `list[int]` | Порядок фрагментов, выбранный пользователем |

**Логика**:
1. Находит капчу по токену
2. Сравнивает `fragment_order` с `correct_order`
3. Если совпадает — возвращает `True`
4. Удаляет капчу из `self.challenges` (одноразовое использование)
5. Если токен не найден — возвращает `False`

**Пример**:
```python
# Правильная сборка
captcha.verify("token123", [0, 1, 2, 3])  # True

# Неправильная сборка
captcha.verify("token123", [3, 2, 1, 0])  # False
```

#### `get_fragment_image(token: str, index: int) -> Optional[Image.Image]`

Возвращает фрагмент пазла как PIL Image. Используется endpoint'ом `/api/captcha/fragment/<token>/<index>`.

#### `get_reference_image(token: str) -> Optional[Image.Image]`

Возвращает reference-изображение (собранный пазл). Используется endpoint'ом `/api/captcha/reference/<token>`.

## Поток работы капчи

### 1. Генерация
```
GET /api/captcha/generate
→ {"token": "...", "fragments": [...], "grid_size": 2, ...}
```

### 2. Получение фрагментов (опционально)
```
GET /api/captcha/fragment/<token>/0
→ Изображение фрагмента 0
```

### 3. Получение образца
```
GET /api/captcha/reference/<token>
→ Reference-изображение
```

### 4. Проверка
```
POST /api/captcha/verify
Body: {"token": "...", "fragment_order": [0, 1, 2, 3]}
→ {"success": true/false}
```

### 5. Авторизация (после успешной капчи)
```
POST / (web.py)
Body: {"login": "admin", "password": "...", "captcha_token": "...", "captcha_order": [...]}
→ Рендерит dashboard или ошибку
```

## Конвертация изображений

### `_convert_to_rgb(img)`
Обрабатывает разные режимы изображений:
- **RGBA** → рисует на белом фоне, затемняет пиксели (эффект старения)
- **RGB** → без изменений
- **P/L/1** → конвертирует в RGB

### `_image_to_base64(img)`
Конвертирует PIL Image в строку data URI:
```
data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...
```
Этот формат可以直接 используется в HTML `<img src="...">`.

## Важные замечания

1. **Одноразовое использование**: После проверки капча удаляется из `self.challenges`.
2. **Хранение в памяти**: Все активные капчи хранятся в `self.challenges` — при перезапуске сервера теряются.
3. **Нет защиты от перебора**: Нет ограничения на количество попыток проверки капчи.
4. **Тестовое изображение**: Если `image/` пуст, генерируется цветное изображение с фигурами.
5. **Режим pieces**: Использует 4 отдельных файла — порядок в файловой системе определяет правильный порядок.
6. **Режим grid**: Разрезает одно изображение — подходит для других сценариев.
