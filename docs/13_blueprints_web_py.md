# Документация: app/blueprints/web.py

## Назначение

Файл `app/blueprints/web.py` реализует **Blueprint для рендеринга HTML-страниц** приложения Demo27. Отвечает за отображение пользовательского интерфейса: страницу входа, дашборды, страницы управления разделами (клиенты, продукция, материалы и т.д.), админ-панель и заметки.

## Blueprint

```python
web_bp = Blueprint("web", __name__)
```

- **Имя**: `web`
- **URL-префикс**: отсутствует (корневые маршруты `/`)
- **Шаблоны**: `web/*.html`
- **Статика**: `web/*.css`, `web/*.js`

## Маршруты (Endpoints)

### 1. `GET/POST /` — Страница авторизации

**Функция**: `login_page()`

| Метод | Описание |
|-------|----------|
| GET | Отображает форму входа с пазл-капчей |
| POST | Обрабатывает вход пользователя |

**Логика POST**:
1. Извлекает `login` и `password` из формы
2. Капча временно отключена (`captcha_ok = True`)
3. Валидация: проверка заполненности полей
4. Поиск пользователя по логину в БД
5. Проверка пароля через `verify_password()`
6. Блокировка при 3+ неудачных попытках
7. Сброс `failed_attempts` при успешном входе
8. Роутинг по ролям:
   - "Администратор" → `/admin/users`
   - "Пользователь" → `/dashboard`

**Параметры шаблона**:
| Параметр | Тип | Описание |
|----------|-----|----------|
| `puzzle_solved` | bool | Собрана ли капча |
| `error_message` | str | Сообщение об ошибке |
| `login` | str | Введённый логин (для повторного отображения) |

**Flash-сообщения**:
- "Пазл собран неверно" — ошибка капчи
- "Неверный логин или пароль" — неверные учётные данные
- "Вы заблокированы" — аккаунт заблокирован
- "Вы успешно авторизовались" — успешный вход

### 11. `GET /image/<filename>` — Раздача изображений

**Функция**: `serve_image(filename)`

**Назначение**: Раздаёт PNG-файлы пазл-капчи из директории `image/`.

**Логика**:
1. Строит путь к файлу
2. Проверяет существование
3. Возвращает файл через `send_file()`
4. Если файл не найден — возвращает 404

### 12. `POST /logout` — Выход из системы

**Декоратор**: `@login_required`

**Функция**: `logout()`

**Логика**:
1. `logout_user()` — завершает сессию Flask-Login
2. `session.clear()` — очищает все данные сессии
3. Flash-сообщение "Вы вышли из системы"
4. Перенаправление на страницу входа

### 13. `POST /api/notes/` — Создание заметки

**Декоратор**: `@login_required`

**Функция**: `create_note()`

**Тело запроса**:
```json
{
    "title": "Заголовок заметки",
    "content": "Текст заметки"
}
```

**Логика**:
1. Проверяет наличие `title` и `content`
2. Создаёт объект `Note` с `id_user=current_user.user_id`
3. Сохраняет в БД
4. Возвращает созданную заметку через `build_note_response()`

**Ответ 201**:
```json
{
    "message": "Заметка создана",
    "note": {
        "id": "00001",
        "title_user": "Заголовок - admin",
        "content": "Текст...",
        "formatted_date": "15.03.2025"
    }
}
```

**Ответ 400**:
```json
{
    "error": "Bad Request",
    "message": "Укажите title и content"
}
```

## Ключевая логика

### Безопасность
- Все страницы (кроме `/` и `/image/`) защищены `@login_required`
- Админ-панель проверяет роль пользователя
- Пароли проверяются через `verify_password()` из `app/auth.py`
- Блокировка аккаунта после 3 неудачных попыток

### Раздача статических файлов
- `IMAGE_FOLDER` указывает на `image/` директорию
- Проверка существования файла перед раздачей
- Защита от path traversal (только файлы из `image/`)

### Роутинг по ролям
| Роль | Перенаправление после входа |
|------|---------------------------|
| Администратор | `/admin/users` |
| Пользователь | `/dashboard` |

## Важные замечания

1. **Капча отключена**: `captcha_ok = True` — проверка капчи временно отключена.
2. **Внутренний импорт**: `Note` импортируется внутри `create_note()` для избежания циклических зависимостей.
3. **Flash-сообщения**: Используются для отображения уведомлений на HTML-страницах.
4. **Единый стиль**: Все маршруты передачи параметров шаблона следуют одному паттерну.
