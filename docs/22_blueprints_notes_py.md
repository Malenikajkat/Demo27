# Документация: app/blueprints/notes.py

## Назначение

Файл `app/blueprints/notes.py` реализует **API для работы с заметками пользователей**. Предоставляет эндпоинты для получения списка заметок (с пагинацией и трансформацией данных) и получения отдельной заметки.

## Blueprint

```python
notes_bp = Blueprint("notes", __name__)
```

Регистрируется с префиксом `/api/notes`.

## Маршруты (Endpoints)

### 1. `GET /api/notes/` — Список заметок

**Функция**: `get_notes()`

**Параметры запроса**:
| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `skip` | int | 0 | Количество пропускаемых записей |
| `limit` | int | 100 | Максимальное количество записей |

**Валидация**:
- `skip >= 0`
- `limit >= 1`

**SQL-запрос**:
```python
select(Note, User.login)
    .join(User, Note.id_user == User.user_id)
    .offset(skip)
    .limit(limit)
```

**Ответ 200**:
```json
{
    "notes": [
        {
            "id": "00001",
            "title_user": "Моя заметка - admin",
            "content": "Текст заметки",
            "formatted_date": "15.03.2025"
        }
    ],
    "total": 42
}
```

**Ответ 400**:
```json
{
    "error": "Bad Request",
    "message": "skip >= 0, limit >= 1"
}
```

**Ответ 500**:
```json
{
    "error": "Internal Server Error",
    "message": "Ошибка базы данных"
}
```

### 2. `GET /api/notes/<note_id>` — Одна заметка

**Функция**: `get_note(note_id)`

**Параметры**: `note_id` — целое число (из URL)

**Ответ 200**:
```json
{
    "id": "00001",
    "title_user": "Моя заметка - admin",
    "content": "Текст заметки",
    "formatted_date": "15.03.2025"
}
```

**Ответ 404**:
```json
{
    "error": "Not Found",
    "message": "Заметка не найден"
}
```

## Трансформация данных

### `build_note_response(note, login)`

Использует функции из `app/utils.py`:

| Поле | Преобразование | Пример |
|------|---------------|--------|
| `id` | `format_note_id(note_id)` → "00001" | Число → строка с нулями |
| `title_user` | `f"{title} - {login}"` | "Заметка - admin" |
| `content` | Без изменений | "Текст..." |
| `formatted_date` | `format_date(created_at)` → "15.03.2025" | datetime → строка |

## Ключевая логика

### Пагинация
Реализована через SQL `OFFSET`/`LIMIT` — загружает только нужную страницу записей.

### JOIN с пользователями
Запрос объединяет `Note` и `User` для получения логина автора.

### Трансформация по API.md
Формат ответа соответствует заданию 5 (API.md):
- ID в формате "00001"
- Поле `title_user` = заголовок + логин
- Дата в формате "ДД.ММ.ГГГГ"

### Обработка ошибок
- `try/except` с `db.session.rollback()` при ошибках БД
- Возврат 500 с JSON-описанием ошибки

## Важные замечания

1. **Только GET**: Нет эндпоинтов для создания/удаления заметок (создание в `web.py`).
2. **Трансформация**: Данные преобразуются при чтении, а не хранятся в БД.
3. **Пагинация**: skip/limit — числовые параметры, валидируются на сервере.
4. **total**: Возвращает общее количество заметок (без учёта пагинации).
5. **join User**: Запрос всегда включает логин автора.
