# Документация: app/repositories/base_repository.py

## Назначение

Файл `app/repositories/base_repository.py` содержит **базовый класс репозитория** с общими CRUD-операциями. Все специализированные репозитории наследуют этот класс.

## Класс `BaseRepository`

### Инициализация

```python
def __init__(self, model):
    self.model = model
```

**Параметры**:
| Параметр | Тип | Описание |
|----------|-----|----------|
| `model` | SQLAlchemy Model | Модель БД для работы |

### Методы

#### `get_all(self, skip=0, limit=100) -> List`

Получает все записи с пагинацией.

**Параметры**:
| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `skip` | int | 0 | Пропуск записей |
| `limit` | int | 100 | Макс. записей |

**SQL**: `SELECT * FROM table OFFSET skip LIMIT limit`

#### `get_by_id(self, item_id) -> Optional`

Получает запись по ID.

**Параметры**:
| Параметр | Тип | Описание |
|----------|-----|----------|
| `item_id` | any | ID записи |

**SQL**: `SELECT * FROM table WHERE id = item_id`

**Возвращает**: Объект модели или `None`

#### `create(self, **kwargs)`

Создаёт новую запись.

**Параметры**: `**kwargs` — поля для создания

**Логика**:
1. Создаёт объект модели: `self.model(**kwargs)`
2. Добавляет в сессию: `db.session.add(item)`
3. Коммитит: `db.session.commit()`
4. Возвращает созданный объект

#### `update(self, item_id, **kwargs)`

Обновляет запись.

**Параметры**:
| Параметр | Тип | Описание |
|----------|-----|----------|
| `item_id` | any | ID записи |
| `**kwargs` | dict | Поля для обновления |

**Логика**:
1. Получает запись по ID
2. Обновляет только переданные поля (если value is not None)
3. Коммитит изменения

**Пример**:
```python
repo.update(1, name="Новое имя", phone="+79991234567")
# Обновит name и phone, остальные поля без изменений
```

#### `delete(self, item_id)`

Удаляет запись.

**Параметры**:
| Параметр | Тип | Описание |
|----------|-----|----------|
| `item_id` | any | ID записи |

**Возвращает**: `True` если удалено, `False` если не найдено

### Ключевая логика

| Аспект | Реализация |
|--------|------------|
| **Пагинация** | SQL OFFSET/LIMIT |
| **Частичное обновление** | Обновляет только non-None поля |
| **Безопасность** | Проверка существования перед update/delete |
| **Транзакции** | commit() после каждой операции |

## Зависимости и связи

| Элемент | Тип связи | Описание |
|---------|-----------|----------|
| `app/extensions.py` | Использует | `db.session` |
| Все репозитории | Наследуют | ClientRepository, ProductRepository и т.д. |
| Все сервисы | Используют | Вызывают CRUD-методы |

## Важные замечания

1. **Generic**: Работает с любой SQLAlchemy-моделью.
2. **Частичное обновление**: `update()` не удаляет поля со значением None.
3. **Нет валидации**: Ожидается, что вызывающий код передаёт корректные данные.
4. **commit() внутри**: Каждая операция сразу коммитится — нет отложенных транзакций.
