# Документация: app/services/auth_service.py

## Назначение

Сервис аутентификации с бизнес-логикой входа, проверки пароля и блокировки аккаунтов.

## Класс `AuthService`

### Инициализация

```python
def __init__(self):
    self.repository = UserRepository()
```

### Метод `login(self, data: dict)`

**Параметры**: `data` — словарь с `login` и `password`

**Логика**:
1. Валидация полей
2. Поиск пользователя по логину
3. Проверка пароля через `verify_password()`
4. Увеличение `failed_attempts` при ошибке
5. Блокировка при 3+ попытках
6. `login_user()` при успехе
7. Сброс `failed_attempts = 0`

**Ответы**:
| Статус | Условие |
|--------|---------|
| 400 | Нет полей |
| 401 | Неверный пароль |
| 403 | Заблокирован |
| 200 | Успех |

## Зависимости и связи

| Элемент | Тип связи |
|---------|-----------|
| `UserRepository` | Использует |
| `app/auth.py` | Использует `verify_password()` |
| `flask_login` | Использует `login_user()` |
