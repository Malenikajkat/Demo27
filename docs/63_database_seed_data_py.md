# Документация: database/seed_data.py

## Назначение

Скрипт для заполнения БД тестовыми пользователями и заметками.

## Функция `seed_database()`

**Логика**:
1. Создаёт Flask-приложение
2. Очищает тестовые данные
3. Создаёт 3 пользователей (admin, user1, user2)
4. Создаёт 5 заметок

## Пользователи

| Логин | Пароль | Роль |
|-------|--------|------|
| admin | admin123 | Администратор |
| user1 | user123 | Пользователь |
| user2 | user234 | Пользователь |

## Заметки

5 заметок распределены между user1 и user2.

## Использование

```bash
python database/seed_data.py
```
