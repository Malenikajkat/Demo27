# Документация: scripts/add_user.py

## Назначение

CLI-скрипт для добавления/обновления пользователей.

## Использование

```bash
python scripts/add_user.py login password [role]
```

## Логика

1. Если пользователь существует — обновляет пароль и роль
2. Если нет — создаёт нового

## Аргументы

| # | Аргумент | Обязательный | По умолчанию |
|---|----------|-------------|--------------|
| 1 | login | Да | — |
| 2 | password | Да | — |
| 3 | role | Нет | "Пользователь" |
