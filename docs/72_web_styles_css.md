# Документация: web/styles.css

## Назначение

Главный CSS-файл (~700 строк) с стилями для всего приложения. Содержит CSS-переменные, сброс стилей, компоненты UI.

## CSS-переменные (Theme)

| Переменная | Значение | Использование |
|------------|----------|--------------|
| `--color-primary` | `#2563eb` | Основной синий |
| `--color-success` | `#16a34a` | Успех |
| `--color-warning` | `#d97706` | Предупреждение |
| `--color-error` | `#dc2626` | Ошибка |
| `--color-info` | `#0891b2` | Информация |
| `--color-background` | `#f1f59` | Фон страницы |
| `--color-surface` | `#ffffff` | Фон карточек |
| `--shadow-sm/md/lg` | тени | Карточки, модалки |
| `--radius-sm/md/lg` | скругления | 6px, 10px, 16px |

## Основные секции

| Секция | Описание |
|--------|----------|
| Сброс | margin:0, padding:0, box-sizing |
| Toast-уведомления | Анимированные уведомления справа сверху |
| Puzzle captcha | Grid 2×2, drag & drop стили |
| Dashboard layout | Sidebar + content |
| Tables | Стили таблиц данных |
| Badges | Статусы (Новый, В работе и т.д.) |
| Modals | Модальные окна |
| Note cards | Карточки заметок (grid) |
| Responsive | Адаптивность |
