# Документация: web/login.html

## Назначение

Страница авторизации с интерактивной пазл-капчей (drag & drop).

## Компоненты

| Компонент | Описание |
|-----------|----------|
| Форма входа | login, password |
| Puzzle captcha | Grid 2×2, drag & drop 4 фрагментов |
| Tray | Контейнер для фрагментов |
| Error messages | Flash-сообщения |

## JavaScript

| Функция | Описание |
|---------|----------|
| Drag & Drop | Перетаскивание фрагментов |
| Validation | Проверка порядка |
| Submit | Отправка формы на POST / |

## API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/` | GET | Отображение формы |
| `/` | POST | Авторизация |
| `/image/<filename>` | GET | Фрагменты капчи |
| `/logout` | POST | Выход |
