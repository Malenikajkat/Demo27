# Документация: web/dashboard.html

## Назначение

Главная страница со статистикой: счётчики клиентов, продукции, материалов, заказов.

## API

| Endpoint | Метод | Данные |
|----------|-------|--------|
| `/api/clients/` | GET | Количество |
| `/api/products/` | GET | Количество |
| `/api/materials/` | GET | Количество |
| `/api/sales-orders/` | GET | Количество |

## Компоненты

- 4 карточки статистики
- AJAX-загрузка при старте
- Обновление по кнопке
