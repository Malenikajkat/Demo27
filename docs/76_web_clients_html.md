# Документация: web/clients.html

## Назначение

Страница управления клиентами: таблица + модальное окно CRUD.

## API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/clients/` | GET | Загрузка таблицы |
| `/api/clients/` | POST | Создание |
| `/api/clients/<id>` | PUT | Обновление |
| `/api/clients/<id>` | DELETE | Удаление |

## Компоненты

- Таблица клиентов (name, inn, address, phone, type)
- Модальное окно формы
- Кнопки: добавить, редактировать, удалить
