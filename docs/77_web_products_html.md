# Документация: web/products.html

## Назначение

Страница управления продукцией: таблица + модальное окно CRUD.

## API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/products/` | GET/POST | Список/создание |
| `/api/products/<id>` | PUT/DELETE | Обновление/удаление |

## Компоненты

- Таблица (name, code)
- Модальное окно формы
- Кнопки CRUD
