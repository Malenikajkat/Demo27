# Документация: web/materials.html

## Назначение

Страница управления материалами: таблица + модальное окно CRUD.

## API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/materials/` | GET/POST | Список/создание |
| `/api/materials/<id>` | PUT/DELETE | Обновление/удаление |

## Компоненты

- Таблица (name, code)
- Модальное окно формы
- Кнопки CRUD
