# Документация: web/operations.html

## Назначение

Страница управления операциями: таблица + модальное окно CRUD.

## API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/operations/` | GET/POST | Список/создание |
| `/api/operations/<id>` | PUT/DELETE | Обновление/удаление |

## Компоненты

- Таблица (name, code)
- Модальное окно формы
- Кнопки CRUD
