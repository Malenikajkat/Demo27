# Документация: web/specifications.html

## Назначение

Страница управления спецификациями: две таблицы (материалы + операции).

## API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/specifications/materials/` | GET/POST | Спецификации материалов |
| `/api/specifications/operations/` | GET/POST | Спецификации операций |

## Компоненты

- Таблица 1: материалы (product, material, quantity)
- Таблица 2: операции (product, operation, time_norm, quantity)
- Форма 1: добавление спецификации материала
- Форма 2: добавление спецификации операции
