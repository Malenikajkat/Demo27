# Документация: web/sales-orders.html

## Назначение

Страница заказов покупателей: таблица + модальное окно + расчёт стоимости.

## API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/sales-orders/` | GET/POST | Список/создание |
| `/api/sales-orders/<id>` | GET | Детали заказа |
| `/api/sales-orders/<id>/cost-calculation` | GET | Расчёт стоимости |

## Компоненты

- Таблица заказов (number, date, client, total)
- Кнопки: просмотр, расчёт стоимости
- Модальное окно: добавление/детали
- Модальное окно: разбивка стоимости
