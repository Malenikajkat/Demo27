# Документация: web/admin-dashboard.html

## Назначение

Админ-панель: управление пользователями.

## API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/admin/users/` | GET | Список |
| `/api/admin/users/` | POST | Создание |
| `/api/admin/users/<id>` | PUT | Обновление |
| `/api/admin/users/<id>` | DELETE | Удаление |

## Компоненты

- Таблица пользователей (login, role, blocked, attempts)
- Кнопки: редактировать, заблокировать/разблокировать, удалить
- Модальное окно редактирования

## Защита

Только для роли "Администратор".
