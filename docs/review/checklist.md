1.1. Возникшие проблемы при запуске

При первом запуске приложения возникла ошибка:

"ModuleNotFoundError: No module named 'psycopg'".

Причина — приложение пыталось использовать драйвер "psycopg", тогда как в зависимостях проекта установлен "psycopg2-binary".

Для устранения проблемы в "app/config.py" была изменена строка формирования адреса подключения к PostgreSQL:

return f"postgresql+psycopg2://{user}:{password}@{host}:{port}/{name}"

После этого возникла ошибка отсутствия базы данных "production_db". База данных была создана в PostgreSQL с помощью DBeaver.

После внесённых изменений приложение успешно запустилось и стало доступно по адресу:

"http://127.0.0.1:5000"

Главная страница открывается в браузере.

3. Первичное знакомство с API

Для ручной проверки HTTP-запросов использовался инструмент Tetiva 1.3.2.

Проверялся API заметок, доступный по адресу:

"http://127.0.0.1:5000/api/notes/"

В ходе изучения файла "app/views/note_view.py" обнаружены два GET-маршрута:

- получение списка заметок;
- получение отдельной заметки по идентификатору.

3.1. Результаты проверки API

№| Проверка| Запрос| Полученный статус| Результат
1| Получение списка заметок| "GET /api/notes/"| 200 OK| Успешно
2| Получение несуществующей заметки| "GET /api/notes/999999"| 404 Not Found| Корректно
3| Проверка отрицательного skip| "GET /api/notes/?skip=-1"| 400 Bad Request| Корректно
4| Проверка нулевого limit| "GET /api/notes/?limit=0"| 400 Bad Request| Корректно
5| Проверка корректных параметров пагинации| "GET /api/notes/?skip=0&limit=10"| 200 OK| Успешно

3.2. Выводы по результатам проверки

1. При запросе списка заметок сервер возвращает статус "200 OK". На момент проверки список был пустым: "notes: []", "total: 0".
2. При запросе заметки с несуществующим идентификатором сервер возвращает "404 Not Found" и сообщение «Заметка не найдена».
3. При передаче отрицательного значения "skip" сервер возвращает "400 Bad Request".
4. При передаче значения "limit=0" сервер также возвращает "400 Bad Request".
5. При передаче корректных параметров пагинации сервер возвращает "200 OK".

Проверки показали, что предусмотренная в обработчике валидация параметров работает корректно.
