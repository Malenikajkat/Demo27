# Отчёт по зависимостям

**Дата:** 24.11.2026  
**Источник:** `requirements.txt` и содержимое ZIP-архива.

## 2. Замечания

| ID | Приоритет | Замечание | Рекомендация |
|---|---|---|---|
| DEP-01 | Важно | Все зависимости заданы нижней границей без точной фиксации версий | Для воспроизводимой сборки сформировать lock-файл или зафиксировать проверенные версии |
| DEP-02 | Важно | Нет отдельного файла dev-зависимостей; `pytest`, `flake8`, `pylint`, `bandit` не перечислены | Добавить `requirements-dev.txt` и выполнять инструменты в CI |
| DEP-03 | Важно | В архиве нет lock-файла и результатов проверки CVE | Добавить lock-файл и регулярный `pip-audit`/аналогичный сканер |
| DEP-04 | Средний | В проекте одновременно указаны `Flask-Migrate` и `alembic`; это допустимо, но требует единообразного процесса миграций | Использовать Flask-Migrate как интерфейс к Alembic и документировать команды миграции |

## 3. Ограничения проверки

- `pip show` подтвердил отсутствие Flask, Flask-SQLAlchemy, Flask-Login, Flask-Migrate, flake8, pylint и bandit в среде проверки.
- Установка из PyPI не выполнена: DNS-разрешение PyPI недоступно.
- `pip-audit` и проверка CVE не выполнялись; утверждать, что зависимости безопасны или уязвимы, без базы advisory нельзя.
- Файл `requirements-dev.txt` добавлен в рамках ревью, чтобы зафиксировать инструменты, необходимые для следующего полноценного прогона.

## 4. Результат

Состав runtime-зависимостей соответствует общей архитектуре Flask/PostgreSQL, однако воспроизводимость установки и контроль уязвимостей недостаточны. Требуются dev-зависимости, фиксирование проверенных версий и автоматический аудит в CI.
