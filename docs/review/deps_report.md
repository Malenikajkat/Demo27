Отсутствие фиксации версий может приводить к различиям в окружениях при повторной установке проекта.

3. Проверка установленных пакетов

Для получения списка установленных пакетов использовалась команда:

python -m pip freeze

В окружении присутствуют основные зависимости проекта, в том числе Flask, Flask-SQLAlchemy, Flask-Login, Flask-Migrate, Werkzeug, Pillow, psycopg2-binary, python-dotenv и Alembic.

Также установлены инструменты разработки и тестирования:

- pytest;
- flake8;
- pylint.

При этом они не указаны в основном "requirements.txt".

Рекомендация: создать отдельный файл "requirements-dev.txt" для зависимостей разработки и тестирования.

4. Проверка актуальности пакетов

Для проверки устаревших пакетов использовалась команда:

python -m pip list --outdated

До обновления были обнаружены:

Пакет| Установленная версия| Доступная версия |
|---|---|---|
pip| 25.1.1| 26.3

После проверки выполнено обновление:

python -m pip install --upgrade pip setuptools

Таким образом, устаревшие версии инструментов установки пакетов были обновлены.

5. Проверка конфликтов зависимостей

Выполнена команда:

python -m pip check

Результат:

Конфликтов между установленными пакетами не обнаружено.

6. Проверка известных уязвимостей

Для аудита использовалась команда:

python -m pip_audit

При первоначальной проверке было получено 15 записей об уязвимостях, относящихся к двум пакетам:

- pip — 12 записей;
- setuptools — 3 записи.

Количество записей не обязательно соответствует количеству уникальных уязвимостей.

После обновления "pip" и "setuptools" аудит был выполнен повторно.

Результат:

No known vulnerabilities found

Повторная проверка установленных пакетов не обнаружила известных уязвимостей.

Следует учитывать, что результат аудита относится к проверенному окружению и не является гарантией отсутствия любых уязвимостей в приложении.

8. Ограничения проверки

Проверка проводилась в текущем виртуальном окружении проекта.

"pip-audit" проверяет установленные пакеты и известные записи об уязвимостях. Результат не заменяет полноценный аудит безопасности исходного кода и всех возможных окружений развёртывания.

Также проверка не подтверждает совместимость проекта со всеми будущими версиями зависимостей.
