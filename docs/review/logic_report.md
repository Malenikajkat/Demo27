**Анализ схемы (`database/schema.sql`):**
- **Плюсы:** Используются правильные типы (UUID для сущностей, `DECIMAL` для денег), настроены каскадные удаления (`ON DELETE CASCADE`), есть проверки `CHECK` для статусов и цен. Создано 17 индексов для внешних ключей и дат — это отличная практика.
