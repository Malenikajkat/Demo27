Карта репозитория Demo27
Дата: 24.11.2026

1. Назначение проекта

Demo27 — веб-приложение для работы с производственными заказами, клиентами, материалами, товарами, операциями и заметками.

Приложение разработано на Python с использованием Flask и SQLAlchemy. Для хранения данных используется PostgreSQL.

2. Структура проекта

- "app/" — основная часть приложения.
  - "blueprints/" — маршруты и обработчики запросов.
  - "dtos/" — объекты передачи данных.
  - "repositories/" — работа с данными и запросами к базе.
  - "services/" — бизнес-логика приложения.
  - "views/" — обработчики и представления.
  - "models.py" — модели базы данных.
  - "config.py" — настройки приложения.
  - "extensions.py" — расширения Flask.
  - "utils.py" — вспомогательные функции.
  - "auth.py" — функции авторизации.
  - "puzzle_captcha.py" — модуль пазл-капчи для авторизации.
- "database/" — SQL-файлы:
  - "schema.sql" — структура базы данных.
  - "order_cost_query.sql" — запрос для расчёта стоимости заказа.
- "docs/" — документация проекта. Папка "review/" создана для отчётов по ревью.
- "image/" — изображения проекта.
- "tests/" — автоматические тесты.
- "web/" — HTML-страницы и таблица стилей "styles.css".
- "run.py" — запуск Flask-приложения.
- "requirements.txt" — список зависимостей Python.
- ".gitignore" — список файлов и папок, исключённых из Git.

3. Запуск приложения

1. Установить зависимости командой "python -m pip install -r requirements.txt".
2. Создать базу данных PostgreSQL "production_db".
3. Запустить приложение командой "python run.py".
4. Открыть в браузере "http://127.0.0.1:5000".

4. Проверенные API-маршруты

- "GET /api/notes/" — получение списка заметок. Поддерживает параметры "skip" и "limit".
- "GET /api/notes/<note_id>" — получение заметки по идентификатору.

Проверки выполнены вручную через Tetiva 1.3.2.
