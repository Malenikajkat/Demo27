# Карта репозитория Demo27

## Структура проекта
* `app/` — основной код приложения (маршруты, бизнес-логика).
* `database/` — скрипты для работы с базой данных (миграции, модели).
* `docs/` — документация проекта.
* `scripts/` — вспомогательные скрипты.
* `tests/` — тесты для проверки работоспособности.
* `web/` — HTML-шаблоны и статика (CSS/JS).
* `run.py` — главный файл для запуска приложения.

## Инструкция по запуску
1. Активировать venv: `venv\Scripts\activate`
2. Установить зависимости: `pip install -r requirements.txt`
3. Настроить БД (порт 5267, база production_db).
4. Запустить: `python run.py`
