1. Общая информация

Цель ревью — оценить структуру проекта, качество исходного кода, работу API, согласованность базы данных, безопасность приложения, состояние интерфейса и документации.

Проект Demo27 представляет собой веб-приложение на Python с использованием Flask, SQLAlchemy и PostgreSQL. Основные функции связаны с управлением клиентами, товарами, материалами, операциями, производственными и заказами на продажу, а также заметками.

4. Выполненные исправления

В рамках практической части выполнены три приоритетных исправления. Каждое изменение проверено и сохранено отдельным Git-коммитом с префиксом "fix:".

2. "web/sales-orders.html" — исправлена функция "viewOrder()": устранены ошибки отображения заказа и обеспечен безопасный вывод динамических данных.
3. "web/base-dashboard.html" — исправлен вывод уведомлений: вместо вставки динамических данных через "innerHTML" используются безопасное создание DOM-элементов и "textContent".

После внесённых изменений автоматические тесты пройдены успешно: 14 из 14.
