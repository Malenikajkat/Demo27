## 1. Коротко

Проект аккуратно разбит на слои, пароли хэшируются, исходные тесты проходят (14 из 14). Главная проблема — доступ: почти весь API открыт без входа, а при регистрации можно самому выбрать роль администратора. Вместе с XSS в шаблонах это серьёзная дыра.
