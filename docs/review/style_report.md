# Отчёт по проверке стиля и качества кода

Дата проверки: 25.11.2026

## 1. Использованные инструменты

- flake8 — проверка соответствия стилю Python.
- pylint — статический анализ кода.
- pytest — запуск автоматических тестов.

## 2. Результаты pylint

Итоговая оценка: 8.82/10.

В ходе статического анализа отмечены следующие проблемы:

- Повторяющиеся фрагменты кода в разных модулях.
- Дублирование логики расчёта стоимости материалов и операций.
- Похожие блоки обработки запросов в представлениях и маршрутах.
- Повторяющиеся проверки прав администратора.

Проверены сценарии авторизации, регистрации, работы с заметками,

## 5. Выявленные недостатки

В ходе ревью обнаружены следующие направления для улучшения:

- Устранение длинных строк и замечаний форматирования.
- Удаление неиспользуемых импортов.
- Сокращение дублирования кода.
- Расширение тестирования граничных и ошибочных сценариев.
- Дополнительная проверка обработки некорректных данных в API.

Часть выявленных функциональных недостатков была исправлена
в ходе практической работы. В частности, добавлены проверки
назначения роли при регистрации и допустимого диапазона скидки.

## 6. Вывод

Статический анализ выявил 282 замечания Flake8.
Основная проблема — превышение рекомендуемой длины строк.

Последний запуск pytest завершился успешно: все 33 теста пройдены.

В ходе ревью были не только зафиксированы недостатки,
но и внесены исправления в исходный код и добавлены тесты.

Рекомендуется продолжить устранение замечаний форматирования,
сократить дублирование логики и расширить автоматическое тестирование.
