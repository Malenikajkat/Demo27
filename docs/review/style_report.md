- **Структура.** Чёткое разделение на слои view → service → repository → model — сильная сторона. Минус: параллельно лежит мёртвый слой `app/blueprints/*` (дубли `app/views/*`) и неиспользуемый `AuthService`.
- **Размер модулей.** `sales_order_view.py` (562 строки) содержит расчёты и генерацию номеров; сервис при этом почти пуст.
- **Комментарии.** Учебные блоки «Студенты: …» занимают до 30 строк на модуль, местами неточны или ссылаются на отсутствующие `TZ.md`/`API.md`.
- **Типы.** `-> Optional:` без параметра типа, аннотации в views/services практически отсутствуют.
